## 4. Архитектура схемы

`map-data.js` хранит фото-производные исходные объекты; `room-identification.js` остаётся единственным каталогом соответствий и составных аудиторий. Новый `schematic-layout.js` задаёт только display coordinates по уже существующим ID, режим `rectangular-schematic` для F1 и `source-layout` для остальных этажей.

Версия схемы: `2026-10-09.UI-01.1`. Она независима от `dataVersion: 2026-10-08.1`, `geometryRevision: 2026-10-09.GEO-02`, схемы localStorage и room bindings. Второй каталог учебных номеров не создан.

Renderer строит заливки и реальные hit regions из одной геометрии. На F1 это SVG `rect`; прежних полигонов поверх прямоугольников нет. Центрирование, подписи и логический контур используют display geometry. На этажах 2–7 реальные selectable polygons совпадают с исходными координатами.

`UI-01_CHANGES.json` содержит точные обратимые source hunks и hashes всех 50 baseline-файлов. Новый gate восстанавливает исходные байты, затем прежние ROOM/GEO/FIX gates выполняют свои строгие assertions. Обращение hunks использует callback replacement; LF/CRLF нормализуется только с восстановлением записанных исходных окончаний строк. Подмена содержимого отклоняется.

## 6. Одинаковая толщина стен

Обычные стены рисуются одним SVG path `.map-walls`. Общие коллинеарные отрезки, включая частичные совпадения и обратный порядок, объединяются перед рисованием. Сеть содержит внешний контур, реальные комнатные перегородки, WC, лестничные ограждения, лифты и разделение их ячеек. Заливки не имеют stroke; совпадающие контуры полигонов не накладываются на стены.

Единые токены: `--map-wall-width: 2px`, `--map-wall-color: #38434f`. Применены `vector-effect: non-scaling-stroke`, butt caps, miter joins, непрозрачная плоская линия и `pointer-events: none`. Внешняя линия имеет ту же толщину, что внутренние. Пересечения окрашиваются одной сетью.

В Chrome на всех семи этажах computed width равен 2 px. Независимая проверка пар сегментов не обнаружила положительного перекрытия коллинеарных стен. В растровом срезе при трёх zoom levels число тёмных пикселей: `[2, 1, 1]`; разница обусловлена субпиксельным антиалиасингом, CSS width не меняется. Это не заявление о попиксельном совпадении нового оформления с прежним.

Выделение использует отдельный цвет и тот же 2 px контур. Клавиатурный `:focus-visible` имеет явный 2 px индикатор; стандартная синяя touch-подсветка Chrome отключена. Фокус остаётся доступным, DOM roles/tabindex сохранены у публичных объектов.
